Create Map

Drafts stay in this browser. Export a .tttm package to share or use in a campaign. Choose a brush, then drag to paint. Shift-click or Shift-drag on a painting brush removes only that brush’s value. Use each category’s Erase control to remove that category from squares or edges. Edge strokes stay horizontal or vertical based on where the drag starts. Bounded maps restrict placement to the map; infinite maps allow play beyond its edge.
